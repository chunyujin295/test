#### 结算\(提交任务状态\)接口

| url    | /point/settle   |           |                                                              |        |
| ------ | --------------- | --------- | ------------------------------------------------------------ | ------ |
| header | Authorization   | sign      |                                                              |        |
|        |                 | timestamp |                                                              |        |
| 方法   | post            |           |                                                              |        |
| 参数   | key             | type      | desc                                                         | 必填   |
|        | free\_no        | string    | 积分冻结单号                                                 | 是     |
|        | status<br>      | int       | success 全部成功<br>fail  全部失败<br>partial 部分成功<br>cancel 取消 | 是<br> |
|        | task\_param     | string    | 任务参数 \(没有分块的任务的只传images\)<br>\{<br>"images":\{<br>"total\_count"：100<br>\}，<br>"tiles":\{<br>       "total\_count": 200,<br>       "success\_count": 80<br>     \}<br>\}<br>取消或者任务失败的时候，部分分块 | 是     |

### 4\.1\.2 生成式

#### 预估积分消耗接口

| url    | /generation/getQuote |           |                                                              |      |
| ------ | -------------------- | --------- | ------------------------------------------------------------ | ---- |
| header | Authorization        | sign      |                                                              |      |
|        |                      | timestamp |                                                              |      |
| 方法   | post                 |           |                                                              |      |
| 参数   | key                  | type      | desc                                                         | 必填 |
|        | param<br>            | json      | \{<br>sub\_type,       // 必填: "text\-to\-model" \| "text\-to\-mesh" \| "image\-to\-model" \| "image\-to\-mesh"<br>prompt,         // 文本提示词<br>negative\_prompt,// 负向提示词<br>polygon\_limit,  // 多边形数量限制<br>texture\_size,   // 纹理分辨率<br>provider\_id,    // 必填: 供应商ID，1=triverse<br>model\_version,  // 模型版本<br>file\_key,       // 已上传文件的 key<br>\} | 是   |
| 输出   | total\_balance       | int       | 总积分                                                       |      |
|        | frozen\_balance      | int       | 冻结积分                                                     |      |
|        | consumed             | int       | 本次任务消耗积分                                             |      |
|        | refunded             | int       | 本次任务返还积分                                             |      |

请求示例

```JSON
{
  "param": {
    "sub_type": "text-to-model",
    "provider_id": 1,
    "prompt": "a modern coffee mug",
    "negative_prompt": "blurry, low quality",
    "polygon_limit": 10000,
    "texture_size": 1024,
    "model_version": "v2.0",
    "turbo": true
  }
}
```

响应示例

```JSON
{
  "errorCode": 0,
  "errorMsg": "成功",
  "requestId": "5c0df0c9",
  "data": {
    "business_type": "text-to-model",
    "estimated_points": 150
  }
}
```

#### 创建生成式任务接口

参数与getQuote类似，只是多了个task\_id参数

| url    | /generation/create3DTask |           |                                                              |      |
| ------ | ------------------------ | --------- | ------------------------------------------------------------ | ---- |
| header | Authorization            | sign      |                                                              |      |
|        |                          | timestamp |                                                              |      |
| 方法   | post                     |           |                                                              |      |
| 参数   | key                      | type      | desc                                                         | 必填 |
|        | task\_id                 | string    | 本地任务标识，只做展示用                                     | 是   |
|        | param                    | json      | \{<br>sub\_type,       // 必填: "text\-to\-model" \| "text\-to\-mesh" \| "image\-to\-model" \| "image\-to\-mesh"<br>prompt,         // 文本提示词<br>negative\_prompt,// 负向提示词<br>polygon\_limit,  // 多边形数量限制<br>texture\_size,   // 纹理分辨率<br>provider\_id,    // 必填: 供应商ID，1=triverse<br>model\_version,  // 模型版本<br>file\_key,       // 已上传文件的 key<br>\} | 是   |
| 输出   | freeze\_no               | string    | 积分冻结单号                                                 |      |
|        | status                   | int       | 任务状态 1待处理PENDING 2排队中QUEUED 3运行中RUNNING 4成功SUCCESS 5失败FAILED 6已取消CANCELLED |      |
|        | available\_points        | int       | 可用积分                                                     |      |
|        | frozen\_points           | int       | 冻结积分                                                     |      |
|        | total\_balance           | int       | 总积分                                                       |      |

示例请求\-文生3D模型：

```JSON
{
  "task_id": "task_20260607_001",
  "param": {
    "sub_type": "text-to-model",
    "provider_id": 1,
    "prompt": "a modern coffee mug with ceramic texture",
    "negative_prompt": "blurry, low quality",
    "polygon_limit": 10000,
    "texture_size": 1024,
    "model_version": "v2.0"
  }
}
```

示例请求\-图生3D模型：

```JSON
{
  "task_id": "task_20260607_002",
  "provider_id": 1,
  "param": {
    "sub_type": "image-to-mesh",
    "provider_id": 1,
    "file_key": "uploads/user1/20260607/photo.jpg",
    "polygon_limit": 20000,
    "texture_size": 2048
  }
}
```

示例响应

```JSON
{
  "errorCode": 0,
  "errorMsg": "成功",
  "requestId": "5c0df0c9",
  "data": {
    "freeze_no": "FRZ20260607001", // 冻结号，后续查询使用它
    "status": 3,
    "available_points": 850,
    "frozen_points": 150,
    "total_balance": 1000
  }
}
```
