## 4\.1 APP

- 查询用户积分

| url    | /point/outline    |           |          |      |
| ------ | ----------------- | --------- | -------- | ---- |
| 方法   | post              |           |          |      |
| header | Authorization<br> | sign      |          |      |
|        |                   | timestamp |          |      |
| 参数   | key               | type      | desc     | 必填 |
|        | 不填              |           |          |      |
| 输出   | total\_balance    | int       | 总积分   |      |
|        | frozen\_balance   | int       | 冻结积分 |      |
|        | available\_points | int       | 可用积分 |      |

参考输出

```JSON
{
    "errorCode": 0,
    "errorMsg": "成功",
    "requestId": "5778d54a",
    "data": {
        "available_points": 580,
        "frozen_points": 0,
        "total_balance": 580
    }
}
```

- 估算消耗积分接口

| url    | /point/estimate      |            |                                                              |      |
| ------ | -------------------- | ---------- | ------------------------------------------------------------ | ---- |
| header | Authorization        | sign       |                                                              |      |
|        |                      | timestamp  |                                                              |      |
| 方法   | post                 |            |                                                              |      |
| 参数   | key                  | type       | desc                                                         | 必填 |
|        | business\_type       | string<br> | 业务类型，参考如下：<br>"sc" 空间计算<br>"sc\_export" 空间计算数据导出<br>"format\_convert"  格式转换<br>"dsm\_dom" DSM / DOM<br>"dense\_pointcloud" 稠密点云<br>"mesh" MESH（OBJ / OSGB\)<br>"3dgs\_self" 3DGS（自有）<br>"3dgs\_gaode" 3DGS（高德云镜高斯<br>"3dgs\_third" 3DGS（第三方） | 是   |
|        | task\_param<br>      | json<br>   | 任务参数<br>\{<br>"images":\{<br>"total\_count"：100<br>\}，<br>"tiles":\{<br>       "total\_count": 200<br>     \}<br>\} | 是   |
| 输出   | estimate\_points<br> | int        | 计算消耗                                                     |      |
|        | total\_balance       | int        | 总积分                                                       |      |
|        | frozen\_balance      | int        | 冻结积分                                                     |      |
|        | available\_points    | int        | 可用积分                                                     |      |

参考请求：

```JSON
{
  "business_type": "3dgs_gaode",
  "task_param": {
    "images": { "total_count": 500 },
    "tiles":  { "total_count": 10}
  }
}
```

参考响应:

```JSON
{
    "errorCode": 0,
    "errorMsg": "成功",
    "requestId": "b6a90313",
    "data": {
        "estimate_points": 100,
        "available_points": 500,
        "frozen_points": 0,
        "total_balance": 500
    }
}
```

- 冻结积分\(创建任务\)接口

| url    | /point/freeze    |            |                                                              |                                    |
| ------ | ---------------- | ---------- | ------------------------------------------------------------ | ---------------------------------- |
| header | Authorization    | sign       |                                                              |                                    |
|        |                  | timestamp  |                                                              |                                    |
| 方法   | post             |            |                                                              |                                    |
| 参数   | key              | type       | desc                                                         | 必填                               |
|        | business\_id<br> | string<br> | 业务id                                                       | 可选\(本地的job\_id或者block\_id\) |
|        | business\_type   | string     | 业务类型，参考如下：<br>"sc" 空间计算<br>"sc\_export" 空间计算数据导出<br>"format\_convert"  格式转换<br>"dsm\_dom" DSM / DOM<br>"dense\_pointcloud" 稠密点云<br>"mesh" MESH（OBJ / OSGB\)<br>"3dgs\_self" 3DGS（自有）<br>"3dgs\_gaode" 3DGS（高德云镜高斯<br>"3dgs\_third" 3DGS（第三方） | 是                                 |
|        | task\_param<br>  | json       | 任务参数<br>\{<br>"images":\{<br>"total\_count"：100<br>\}，<br>"tiles":\{<br>       "total\_count": 200<br>     \}<br>\} | 是                                 |
| 输出   | freeze\_no<br>   | string     | 积分冻结标识                                                 |                                    |
|        | total\_balance   | int        | 总积分                                                       |                                    |
|        | frozen\_balance  | int        | 冻结积分                                                     |                                    |

参考请求：

```JSON
{
  "business_type": "3dgs_gaode",
  "task_param": {
    "images": { "total_count": 500 },
    "tiles":  { "total_count": 10 }
  }
}
```


参考输出：

```JSON
{
    "errorCode": 0,
    "errorMsg": "成功",
    "requestId": "9dc3295c",
    "data": {
        "freeze_no": "06b052b25f4c47feb978ad864e6df344",
        "available_points": 480,
        "frozen_points": 100,
        "total_balance": 580
    }
}
```

- 结算\(提交任务状态\)接口

| url    | /point/settle   |           |                                                              |        |
| ------ | --------------- | --------- | ------------------------------------------------------------ | ------ |
| header | Authorization   | sign      |                                                              |        |
|        |                 | timestamp |                                                              |        |
| 方法   | post            |           |                                                              |        |
| 参数   | key             | type      | desc                                                         | 必填   |
|        | free\_no        | string    | 积分冻结单号                                                 | 是     |
|        | status<br>      | int       | success 全部成功<br>fail  全部失败<br>partial 部分成功<br>cancel 取消 | 是<br> |
|        | task\_param     | string    | 任务参数 \(没有分块的任务的只传images\)<br>\{<br>"images":\{<br>"total\_count"：100<br>\}，<br>"tiles":\{<br>       "total\_count": 200,<br>       "success\_count": 80<br>     \}<br>\}<br>取消或者任务失败的时候，部分分块 | 是     |
| 输出   | total\_balance  | int       | 总积分                                                       |        |
|        | frozen\_balance | int       | 冻结积分                                                     |        |
|        | consumed        | int       | 本次任务消耗积分                                             |        |
|        | refunded        | int       | 本次任务返还积分                                             |        |

参考请求：

```JSON
{
  "freeze_no": "06b052b25f4c47feb978ad864e6df344",
  "status": "partial",
  "task_param": {
    "images": { "total_count": 500 },
    "tiles":  { "total_count": 10, "success_count": 8 }
  }
}
```

参考返回:

```JSON
{
    "errorCode": 0,
    "errorMsg": "成功",
    "requestId": "5c0df0c9",
    "data": {
        "consumed": 80,
        "refunded": 20,
        "available_points": 500,
        "frozen_points": 0,
        "total_balance": 500
    }
}
```
