# 积分系统全流程测试用例

> 覆盖生成式、空三、生产三种任务类型的 freeze → settle 完整链路。
> 测试用例按 `PointManager`、提交端、Engine 结算端、分布式/异常 四个维度组织。

## 测试文件结构

```
Test/testPoints/
  CMakeLists.txt
  testPointManager.cpp       ← PointManager API 单元测试
  testFreezeSubmit.cpp       ← 提交时冻结流程
  testSettleEngine.cpp        ← Engine 侧结算流程 (含哨兵机制)
  testPointsDistributed.cpp   ← 分布式 + 异常场景
```

## 三、Engine 侧结算流程

### 3.1 生成式 — GenTaskThread::ProcessRunningJobs

| # | 场景 | 预期 |
|---|------|------|
| 33 | COMPLETED | 后端自动结算, Engine 只需回填积分余额到 job |
| 34 | FAILED | 后端自动处理, Engine 回填 error_message |
| 35 | 积分余额回填 | ApplyResponse 后 point_info.available_points/total_balance 更新 |

### 3.2 空三 — ExecTaskFileV2::ATLASTTASKTYPE

| # | 场景 | 预期 |
|---|------|------|
| 36 | AT 全部 Step 完成 | ATLASTTASKTYPE 分支 → SettlePoints(freeze_no, "success", taskParamJson) |
| 37 | 结算在 feedback 写终态之前 | feedback 先设 STATUS_COMPLETE, 再调 SettlePoints |
| 38 | 结算失败不更新状态 | SettlePoints 返回 consumed=0 → 不移动 job 到 Completed/, 下轮重试 |
| 39 | 结算成功 | consumed > 0, 更新 point_info, 移动 job 到 Completed/ |
| 40 | taskParamJson 与冻结时一致 | 从 tg 重建的 images.total_count + tiles.total_count 匹配 |

### 3.3 生产 — ExecTaskFileV2::OnTileJobFinished

| # | 场景 | 预期 |
|---|------|------|
| 41 | 单个 Tile 完成(非最后一个) | 写哨兵, 不触发结算 |
| 42 | 最后一个 Tile 完成 | 哨兵数 == Tile 目录数 → 触发结算 |
| 43 | 哨兵文件内容 | 空文件, 文件名 = <TileName>.done |
| 44 | settle.lock 互斥 | 只有一个节点拿到锁 |
| 45 | 二次确认 | 拿到锁后重新计哨兵, 防止 TOCTOU |
| 46 | freeze_no 读取 | 从 productionDir/freeze_no.bin XOR 解密 |
| 47 | imageCount 获取 | 从 BlockObject 读取 (共享存储) |
| 48 | taskParamJson 重建 | BuildTaskParamJson(imageCount, totalTiles) |
| 49 | 结算参数 | SettlePoints(freeze_no, settleStatus, taskParamJson) |
| 50 | settleStatus 映射 | 全部 completed → "success"; 有 failed/cancelled → "fail" |
| 51 | 结算成功 | 写 settled.done, 释放锁 |
| 52 | 结算失败 | 不写 settled.done, 释放锁, 下个 Tile 完成时重试 |
| 53 | 幂等: 已结算再次触发 | settled.done 存在 → 跳过 |

### 3.4 终态分布统计

| # | 场景 | 预期 |
|---|------|------|
| 54 | 全部 Tile 成功 | completed=N, failed=0, cancelled=0 |
| 55 | 部分 Tile 失败 | completed + failed = N, settleStatus="fail" |
| 56 | 部分 Tile 取消 | completed + cancelled = N, settleStatus="fail" |
| 57 | 混合终态 | completed + failed + cancelled = N |
| 58 | 空 Tile 目录 | totalTiles=0 → 不触发结算 |

## 四、分布式 + 异常场景

### 4.1 哨兵机制分布式

| # | 场景 | 预期 |
|---|------|------|
| 59 | 两个 Tile 同时在不同节点完成 | settle.lock 保证只有一个结算 |
| 60 | 节点 A 写哨兵后 crash | 哨兵已落盘, 节点 B 处理其他 Tile 后触发结算 |
| 61 | 结算中途节点 crash | settled.done 未写入, 下个节点重试结算 (幂等) |
| 62 | 网络分区恢复 | 哨兵文件在共享存储, 不受网络分区影响 |

### 4.2 freeze_no 存取

| # | 场景 | 预期 |
|---|------|------|
| 63 | freeze_no.bin 不存在 | 跳过结算, LOGE |
| 64 | freeze_no.bin 损坏 | XOR 解密后为空或乱码, 跳过结算 |
| 65 | 不同 production 的 freeze_no 隔离 | 不同 Production_P/ 目录, 互不干扰 |

### 4.3 结算参数一致性

| # | 场景 | 预期 |
|---|------|------|
| 66 | 冻结时 taskParamJson vs 结算时 taskParamJson | images.total_count, tiles.total_count 一致 |
| 67 | tileCount 动态获取 | 从 productionDir 下 Tile_* 目录数, 与冻结时一致 |
| 68 | imageCount 从 Block 获取 | Block 在共享存储, 所有节点读到相同值 |

### 4.4 异常恢复

| # | 场景 | 预期 |
|---|------|------|
| 69 | SettlePoints HTTP 超时 | 不写 settled.done, 下轮重试 |
| 70 | 结算 HTTP 返回 errorCode != 0 | 同上, 不标记已结算 |
| 71 | 冻结时写入 freeze_no.bin 后 crash | 文件已落盘, 重启后结算可用 |
| 72 | settled.done 写入后 crash | 幂等保护, 重启后不再结算 |

### 7.3 testFreezeSubmit.cpp — 提交时冻结流程 (用例 #20~#32)

```cpp
// Test/testPoints/testFreezeSubmit.cpp
// 覆盖: 生成式/空三/生产 三种提交场景的冻结流程

#include "Core/PointManager.h"
#include "Core/GenTaskOptions.h"
#include "Core/GenTaskAPI.h"
#include "Core/BlockObject.h"
#include "Core/Logging.h"
#include "Core/File.h"

#include <QDir>
#include <QString>
#include <QUuid>
#include <cstdio>
#include <string>

using namespace AI3D::CORE;

static int g_failures = 0;
#define TEST_ASSERT(cond, msg) do { if (!(cond)) { ++g_failures; LOGE(std::string("FAIL: ") + msg); } } while (0)
#define LOGPASS(msg) LOGI(std::string("PASS: ") + msg)

// ============================== 2.1 生成式提交冻结 ==============================

static void TestGenTaskSubmitFreeze()
{
    QString tmpDir = QDir::tempPath() + "/test_gen_freeze_"
        + QUuid::createUuid().toString(QUuid::WithoutBraces);
    QDir().mkpath(tmpDir);

    BlockObject block(tmpDir.toStdString());
    block.GetIdMutual() = 1;
    block.Init();
    block.SetStatus(jobsta_e::STATUS_NEW);
    QDir().mkpath(QString::fromStdString(block.GetPath()));

    auto& task = block.GetTaskInfoMutual();
    task.blockString  = "Block_1";
    task.blockName    = block.GetName();
    task.blockId      = 1;
    task.projectfile_ = tmpDir.toStdString();
    task.block_task_category = 1;
    task.gen_options.gen_params.sub_type = GenTaskSubType::TEXT_TO_MODEL;
    task.gen_options.gen_params.prompt   = "test";

    std::string pendingPath = tmpDir.toStdString() + "/jobs_gen/Pending/";
    QDir().mkpath(QString::fromStdString(pendingPath));

    GenTaskAPI::SubmitResult result = GenTaskAPI::SubmitGenTask(
        task, "testuser@example.com", pendingPath);
```

```cpp
        std::string tileName = "Tile_" + std::string(3 - std::to_string(tileIndex).size(), '0')
            + std::to_string(tileIndex);
        std::string tileDir = productionDir + "/" + tileName;

        // 写 feedback
        JobFeedBack_s fb;
        fb.Status  = finalStatus;
        fb.Percent = (finalStatus == jobsta_e::STATUS_COMPLETE) ? 100.0f : 0.0f;
        std::string fbPath = tileDir + "/JF_job_tile_" + std::to_string(tileIndex) + ".bin";
        fb.save_with_retry(fbPath, false);

        // 写哨兵
        std::string sentinelPath = sentinelDir + "/" + tileName + ".done";
        std::ofstream ofs(sentinelPath);
        ofs.close();
    }

    // 模拟 OnTileJobFinished 中的哨兵收齐 + 结算
    bool TrySettle()
    {
        auto sentinelFiles = AICORE::File::GetFileList(sentinelDir, "*.done");
        int sentinelCount = (int)sentinelFiles.size();
        if (sentinelCount < totalTiles)
            return false;

        std::string settleLock = sentinelDir + "/settle.lock";
        FILE* fp = AICORE::File::FopenDenyWriteLockUtf8(settleLock);
        if (fp == NULL) return false;

        // 二次确认
        sentinelFiles = AICORE::File::GetFileList(sentinelDir, "*.done");
        if ((int)sentinelFiles.size() < totalTiles) { fclose(fp); return false; }

        // 读 freeze_no
        std::string fn;
        {
            std::ifstream ifs = AICORE::File::OpenIfstreamUtf8(
                productionDir + "/freeze_no.bin", std::ios::binary);
            fn = ReadEncryptedString(ifs);
        }

        // 统计终态
        int completed = 0, failed = 0, cancelled = 0;
        auto tileDirs = AICORE::File::GetDirList(productionDir);
        for (auto& td : tileDirs) {
            if (td.find("Tile_") == std::string::npos) continue;
            auto fbFiles = AICORE::File::GetFileList(productionDir + "/" + td, "JF_*.bin");
            for (auto& fbFile : fbFiles) {
                JobFeedBack_s feedback;
                if (feedback.load_with_retry(productionDir + "/" + td + "/" + fbFile, false)) {
                    switch (feedback.Status) {
                    case jobsta_e::STATUS_COMPLETE: completed++; break;
                    case jobsta_e::STATUS_FAILURE:  failed++;    break;
                    case jobsta_e::STATUS_CANCLE:   cancelled++; break;
                    }
                }
                break;
            }
        }

        // 结算
        std::string settleStatus = (failed > 0 || cancelled > 0) ? "fail" : "success";
        std::string taskParamJson = BuildTaskParamJson(imageCount, totalTiles);
        PointSettleInfo sr = PointManager::SettlePoints(fn, settleStatus, taskParamJson);

        // 写 settled.done
        std::ofstream done(sentinelDir + "/settled.done");
        done << "done";
        fclose(fp);

        return sr.consumed > 0 || sr.refunded > 0;
    }

    void Cleanup() { QDir(QString::fromStdString(productionDir)).removeRecursively(); }
};
```

```cpp
    auto files = AICORE::File::GetFileList(env.sentinelDir, "*.done");
    std::string lockPath = env.sentinelDir + "/settle.lock";
    FILE* fp = AICORE::File::FopenDenyWriteLockUtf8(lockPath);
    if (fp != NULL) {
        // 模拟: 结算成功但写 settled.done 前 crash
        // 不写 settled.done 就 fclose
        fclose(fp);
    }

    // settled.done 不存在 → 下次应该重试
    TEST_ASSERT(!AICORE::File::ExistsFile(env.sentinelDir + "/settled.done"),
                "#61 settled.done should not exist after crash");
    LOGPASS("#61 Mid-settlement crash — retry on recovery");

    env.Cleanup();
    QDir(tmp).removeRecursively();
}

static void TestFreezeNoBinCorrupted()
{
    QString tmp = QDir::tempPath() + "/test_dist_corrupt_"
        + QUuid::createUuid().toString(QUuid::WithoutBraces);
    QDir().mkpath(tmp);

    std::string productionDir = tmp.toStdString() + "/Block_1/Recon_1/Productions/Prod_1";
    std::string sentinelDir  = productionDir + "/sentinels";
    AICORE::File::CreateDirIfNotExists(productionDir, true);
    AICORE::File::CreateDirIfNotExists(sentinelDir, true);

    // 写入损坏的 freeze_no.bin
    {
        std::string path = productionDir + "/freeze_no.bin";
        std::ofstream ofs(path, std::ios::binary);
        char garbage[] = "not-valid-data";
        ofs.write(garbage, sizeof(garbage));
        ofs.close();
    }

    // 写哨兵
    std::ofstream ofs(sentinelDir + "/Tile_000.done"); ofs.close();

    // 读取应失败 (长度字段解密后为乱码)
    std::ifstream ifs = AICORE::File::OpenIfstreamUtf8(
        productionDir + "/freeze_no.bin", std::ios::binary);
    if (ifs.is_open()) {
        unsigned char key = 0xAB;
        unsigned int encLen = 0;
        ifs.read(reinterpret_cast<char*>(&encLen), sizeof(encLen));
        unsigned int len = encLen ^ (key | (key << 8) | (key << 16) | (key << 24));
        // 损坏数据: len 可能是极大值, 读不到足够字节
        TEST_ASSERT(len > 1000000 || len == 0, "#64 corrupted freeze_no.bin: should fail gracefully");
    }
    LOGPASS("#64 Corrupted freeze_no.bin");

    QDir(tmp).removeRecursively();
}
```
